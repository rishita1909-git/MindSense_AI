# 🧠 MindSense AI

MindSense AI is an AI-powered mental health monitoring web application developed using Flask and Machine Learning. It helps users track their mental well-being through journal analysis, sentiment analysis, AI-based depression prediction, social media text analysis, and an AI chatbot.

---

## 🚀 Features

- 🔐 User Registration & Login
- 📝 Daily Journal Writing
- 😊 Mood Tracking
- 🤖 AI Depression Prediction (Machine Learning)
- 💬 AI Chatbot (Gemini API)
- 📱 Social Media Text Analysis
- 📊 Dashboard with Mood Analytics
- 📄 PDF Report Generation
- 😊 Face Detection *(Coming Soon)*
- 🎤 Voice Analysis *(Coming Soon)*

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/rishita1909-git/MindSense_AI.git
```

Move into the project folder

```bash
cd MindSense_AI
```

Create a virtual environment

```bash
python -m venv venv
```

Activate virtual environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```

Open in browser

```
http://127.0.0.1:5000
```
